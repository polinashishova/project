# Датасет результатов анализа безопасности

## Описание

Данный датасет содержит результаты анализа безопасности
авторизованного локального ресурса `127.0.0.1`.

Датасет сформирован в рамках практической работы по изучению
инструментов анализа сетевой безопасности.

Для получения результатов использовались:

- **Nmap** — обнаружение открытых портов, определение сервисов
  и их версий;
- **Masscan** — обнаружение открытых TCP-портов;
- **Nikto** — проверка веб-сервисов на типовые проблемы
  безопасности.

### Описание файлов

| Файл                   | Назначение                                 |
| ---------------------- | ------------------------------------------ |
| `scan_findings.csv`    | Единый CSV-файл с результатами анализа     |
| `nmap_result.xml`      | Исходный результат сканирования Nmap       |
| `masscan_output.txt`   | Исходный результат сканирования Masscan    |
| `nikto_report.html`    | HTML-отчёт Nikto                           |
| `scan_findings.meta`   | Метаданные датасета                        |
| `expert_assessment.md` | Экспертная оценка обнаруженных результатов |
| `sources.md`           | Использованные источники и документация    |

## Формат CSV

Файл `scan_findings.csv` содержит следующие поля:

| Поле             | Описание                              |
| ---------------- | ------------------------------------- |
| `finding_id`     | Уникальный идентификатор находки      |
| `tool`           | Инструмент, обнаруживший результат    |
| `target_ip`      | IP-адрес исследуемой цели             |
| `port`           | Обнаруженный порт                     |
| `severity`       | Оценка уровня значимости              |
| `category`       | Категория результата                  |
| `description`    | Описание обнаруженного результата     |
| `expert_comment` | Экспертный комментарий и рекомендация |

## Результаты анализа

В ходе сканирования были получены следующие результаты.

### Nmap

Nmap обнаружил два открытых TCP-порта:

* `631/tcp` — сервис CUPS версии 2.4;
* `8000/tcp` — HTTP-сервис SimpleHTTPServer 0.6.

### Masscan

Masscan обнаружил:

* `445/tcp`;
* `135/tcp`.

### Nikto

Nikto был запущен для проверки веб-сервиса.

В сформированном отчёте Nikto дополнительных findings
не зафиксировано.

Отсутствие результатов Nikto означает, что используемые
автоматические проверки не выявили соответствующих проблем.
Это не является доказательством абсолютного отсутствия
уязвимостей.

## Оценка результатов

Обнаруженные открытые порты в данном датасете имеют уровень
`info`.

Открытый порт сам по себе не является подтверждением наличия
уязвимости. Для определения реального уровня риска требуется
дополнительная проверка назначения сервиса, его конфигурации,
версии программного обеспечения и доступности из сети.

Подробная экспертная оценка приведена в файле
[`expert_assessment.md`](expert_assessment.md).

## Ограничения

Результаты получены в конкретный момент времени и зависят от
конфигурации исследуемой системы.

Автоматические инструменты могут обнаруживать не все существующие
проблемы безопасности. Поэтому результаты сканирования требуют
дополнительного анализа.

Датасет не следует рассматривать как полный аудит безопасности
исследуемой системы.

## Правовой статус

Сканирование проводилось только в отношении локального
авторизованного ресурса `127.0.0.1`.

Инфраструктура GitHub и сторонние информационные системы
не сканировались.

Результаты используются исключительно в учебных целях в рамках
практической работы.
